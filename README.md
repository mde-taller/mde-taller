# MDE · Taller

App de órdenes de trabajo de MDE Electromecánica: oficina (PC), depósito y mecánicos (celular).

- **App:** se publica con GitHub Pages desde la rama `main`.
- **Base de datos:** Supabase. La conexión está en `js/config.js` (solo la clave pública).
- **Esquema:** `base-de-datos/` (sin datos de clientes ni repuestos).
- **Creación de usuarios:** función de Supabase en `supabase/functions/crear-usuario`.
